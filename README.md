### What I'm Building

A habit journal built around consistency rather than streaks.

Built with React, TypeScript, Supabase, PostgreSQL, and Cloudflare.

Some of the engineering work includes:

- Offline support and optimistic updates
- PostgreSQL authorization and account-scoped data
- Automated testing and deployment workflows
